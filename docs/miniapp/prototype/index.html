关于我们

项目介绍

校园猫咪档案馆收录校内流浪与家养猫咪的档案，帮助师生认识、关注与科学照护它们。

资料维护原则

所有信息以客观事实为准；绝育、健康等状态未知时标注「尚未确认」，不臆测；位置仅到校园区域级，不公开精确窝点。

信息纠错

发现信息有误或猫咪情况变化，请联系管理员更新。（联系方式由负责人确认后填写）
