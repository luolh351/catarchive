# 小程序项目规划

## 产品

- 产品名称：校园猫咪档案馆
- 目标用户：本校师生、爱猫人士（只读）；授权管理员（维护）
- 要解决的问题：校内猫咪信息分散、易遗忘，缺一个权威的档案与近况记录入口
- 用户最重要的一次操作：浏览猫咪档案（学生）/ 维护猫咪档案（管理员）
- 核心业务规则：猫咪去向分四类——在校 / 毕业(已领养) / 休学(不知所踪) / 喵星(已去世)；在校猫可标记"待领养"
- 使用者和协作方式：普通用户只读；管理员用微信 openid 白名单鉴权，superadmin 可转让、可管理 editor 名单
- 数据保留和共享要求：归档不物理删除，写审计日志；公开读取只返回已发布档案所需字段；管理员身份备注仅在管理员间可见
- 外部业务资料来源：无（用户后续提供首批 5–10 只猫咪数据）
- 高影响字段确认状态：已确认（2026-10-25）

## 已有项目盘点（新项目不适用）

- 项目根目录：d:\catarchive
- 用户可见功能：见首版范围
- 基础设施：微信云开发 CloudBase（数据库/云存储/云函数）
- 管理能力：小程序内隐藏工作台（角色权限隔离）
- 高风险能力：删除→改为归档；授权变更（转让/增删管理员）
- 未确认或无法读取项：AppID、CloudBase EnvId、首批素材
- 盘点日期和源码版本：2026-10-25 / 无源码

## 首版范围

- 必须实现：
  - 猫咪列表、猫咪详情（照片/声音/毛色/性别/绝育/性格/常出没/状况/最近情况 + 近况时间线）
  - 搜索与筛选（名字/昵称 + 毛色/性格/区域标签；四去向状态标签）
  - 管理员身份校验（服务端 openid）；新增/编辑/归档档案（中文表单、预览、保存反馈）
  - 照片上传/预览/设封面/移除；声音上传与播放
  - 更新近况（时间线）、归档与审计（写 admin_audit_logs）
  - superadmin 管理名单（增删 editor、转让 super）、editor 身份备注（姓名/专业/班级/宿舍/备注，管理员间可见）
  - 关于我们（静态）、登录/权限提示页
  - 加载/空/错误/表单校验/保存反馈等基础体验
- 暂不实现：评论/帖子/社区（V2）；学生投稿审核（V1.1）；地图/AI 识别；独立 Web 后台；跨校多租户；任何商业功能
- 上线成功标准：
  - 学生能浏览全部已发布猫咪并打开详情；缺信息显示"尚未确认"不崩溃
  - 搜索/筛选正确；未授权用户直调写入云函数被服务端拒绝
  - 管理员可增改归档、上传替换照片、新增近况并显示时间线
  - 每次重要修改记录操作者与时间；表单提示清楚、失败可重试、离开未保存提示
  - 代码/配置/文档齐全，真密钥不入库；AI 列出未执行/未验证/需用户处理事项
- 首版范围确认日期：2026-10-25

## 设计

- UI 主方案：B · 品牌定制（蓝底 + 白色大圆角卡片 + 分段状态标签）
- 预览画布：375px
- 主组件库：TDesign MiniProgram（实现前复核版本与 LICENSE）
- tabBar 方案：原生本地 PNG（查猫 / 关于）
- UI 方案对比位置：`docs/miniapp/ui-options/index.html`
- 设计系统位置：`docs/miniapp/design-system.md`
- 设计系统来源/版本：微信设计指南 + TDesign MiniProgram；版本实现前复核
- WXML/WXSS 可落地检查：已通过（有待确认项：TDesign 当前版本/许可证、卡片阴影安卓真机表现）
- 原型位置：`docs/miniapp/prototype/index.html`
- 原型确认日期：2026-10-25
- API/存储字段到 UI 字段映射：
  - name→名字；aliases→昵称（搜索用）
  - coatColor→毛色；gender→性别；sterilizationStatus + sterilizedAt→绝育情况/绝育时间
  - personalityTags→性格；usualLocations→常出没；healthNotes→状况；latestNote→最近情况
  - lifeStatus→去向状态（在校/毕业/休学/喵星）；isAdoptable→待领养徽标
  - photos→照片（封面）；voice→声音；cat_updates→近况时间线
- 无法继承的样式差异与原因：B 方案卡片阴影在低端安卓可能偏弱，真机验证，必要时降为浅描边

## 能力

- 微信身份：需要（管理员 openid 鉴权，服务端用 cloud.getWXContext().OPENID）
- 头像昵称：不需要（管理员备注用姓名/专业/班级/宿舍，不使用微信头像昵称授权）
- 手机号：不需要
- 图片或文件：需要（猫咪照片上传/预览/设封面；声音上传与播放）

## 状态与分享

- 开始新流程时：保留（不自动清空草稿，提示未保存）
- 返回或重新选择时：保留（列表筛选状态）

- 多页面状态唯一来源：CloudBase 数据 + 本地页面状态
- 分享给朋友：需要（分享猫咪详情）
- 分享到朋友圈：需要
- 分享冷启动重建方式：稳定入口（猫咪 id 参数）
