## 已确认决策

### 决策：管理入口形态
- 选择：小程序内角色权限隔离的隐藏管理工作台（普通用户不可见，管理员微信登录后可见）
- 原因：符合项目书 V1.0，改资料不动代码，工作量可控
- 备选方案：独立电脑网页后台（开发量大、需域名，放到后续）
- 费用或审核风险：低
- 用户确认：是（2026-10-25）
- 确认日期：2026-10-25

### 决策：后台方案
- 选择：微信云开发 CloudBase（云数据库 + 云存储 + 云函数）
- 原因：免费额度够起步、超出按量付费，无需自建服务器；写入权限在服务端校验
- 备选方案：自有 HTTPS 后台（配置成本高）
- 费用或审核风险：超出免费额度按量付费（生产环境创建前需用户确认）
- 用户确认：是（2026-10-25）
- 确认日期：2026-10-25

### 决策：注册主体
- 选择：个人主体
- 原因：最简单；本项目不涉及交易/付费
- 备选方案：学校/社团组织主体（类目更全但流程复杂）
- 费用或审核风险：部分服务类目受限，需逐项核验；不做交易类功能规避主要风险
- 用户确认：是（2026-10-25）
- 确认日期：2026-10-25

### 决策：角色与治理模型
- 选择：superadmin（可转让）+ editor（人数由 super 控制，不固定）；所有写入走云函数，服务端用可信 openid 校验
- 原因：去掉固定 7 人限制更灵活；super 可转让避免单点失联
- 备选方案：固定 ≤7 平等管理员（用户已推翻）；super 独占增删权（用户改为加回 super）
- 费用或审核风险：低
- 用户确认：是（2026-10-25）
- 确认日期：2026-10-25

### 决策：管理员身份备注可见范围
- 选择：realName/major/className/dorm/note 在管理员（superadmin + editor）之间互相可见；公开接口不返回
- 原因：便于 superadmin 管理团队成员辨认
- 备选方案：仅 super 与本人可见（用户改为管理员间互见）
- 费用或审核风险：含个人敏感信息，需限定可见范围并写入隐私保护指引
- 用户确认：是（2026-10-25）
- 确认日期：2026-10-25
